# Code of Conduct

AETHER is a project for everyone. We expect contributors and maintainers to:

- Be respectful, patient and constructive.
- Critique ideas and code, never people.
- Assume good faith and ask clarifying questions before escalating.
- Respect privacy: do not publish another person's logs, configs or screenshots without
  permission.
- Refuse harassment, discrimination, sexualized content, doxxing and sustained disruption.

Maintainers may warn, moderate or remove contributions and participation that violate
This code applies in the repository, issues, discussions, reviews and any project space.
