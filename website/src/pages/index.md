# AETHER — Your desktop. Your atmosphere. Your AETHER.

> Your desktop. Your atmosphere. Your AETHER.

AETHER is a complete open-source Linux desktop ecosystem built with:

- **Quickshell** shell and QML apps
- **Rust + Ratatui** installer
- **Astro** website
- **Hyprland** configuration and theme/widget system

## Highlights

- Dark‑first, rounded/translucent Material You‑inspired identity
- Consistent design language across shell, apps, installer, website
- First‑class Arch Linux support, with abstraction points for other distros
- Real system stats via `aether-stats`
- Weather with Open‑Meteo (configurable lat/lon)
- Night light via `hyprsunset`, brightness via `brightnessctl`

## Get Started

Quick install (recommended):

```bash
git clone https://github.com/aether-desktop/AETHER.git
cd AETHER
./install.sh
```

See the [Installation](install) guide for details.
