# Frequently Asked Questions

## Can I use AETHER on non-Arch distributions?

AETHER is first‑class on Arch Linux only. The installer has abstraction points for Fedora, openSUSE and NixOS; see the documentation for limitations.

## What are the system requirements?

- Arch Linux (≥ 2019.06)
- Hyprland Wayland (≥ 0.40)
- Quickshell (≥ 0.2)
- PipeWire + WirePlumber (audio)
- NetworkManager (network)
- BlueZ (Bluetooth)

## How do I get support?

Open an issue on GitHub and include the output of `aether doctor`.
