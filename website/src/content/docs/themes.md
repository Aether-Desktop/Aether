# Themes

AETHER includes seven built-in themes:

- **AETHER Dark** – violet aurora on deep atmosphere
- **AETHER Light** – on white surface
- **AETHER AMOLED** – pure black surface
- **AETHER Midnight** – night sky palette
- **AETHER Lavender** – soft purple accent
- **AETHER Ocean** – cyan and teal tones
- **AETHER Forest** – green and amber contrast

Each theme defines semantic color roles, radii, typography, blur and opacity. Dynamic accent extraction uses Quickshell's `ColorQuantizer` on the current wallpaper.

## Importing and Exporting

Themes are JSON files and can be imported/exported from Settings. See the AETHER Settings → Appearance → Themes page.
