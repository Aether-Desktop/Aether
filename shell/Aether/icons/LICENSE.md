# AETHER icon set

These 24x24 stroke icons are original works created for the AETHER project and are
licensed under the MIT License (see the repository `LICENSE`). They are intentionally
simple geometric glyphs so they remain legible at 16-20px in the bar.

Add new icons as `name.svg` with:

- `viewBox="0 0 24 24"`
- `fill="none" stroke="#E8EAF2" stroke-width="1.7"`
- round caps and joins
- no embedded raster images or external references

The shell tints them at runtime via `Aether.Icon`, so the baked stroke color acts as a
mask base.
